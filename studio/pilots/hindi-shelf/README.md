## Editorial boundary

These are independently written Hindi read-aloud adaptations, not automatic
translations. Canonical names stay linked through `«... »` markers. Each scene is
mapped to the English story's approved sourcing ledger and every locale file is
pinned to the exact source-story Git blob. Canonical age/sensitivity guidance is
retained in the parent note. Variant/tradition notes are not flattened for Hindi.

The four new editions remain `in-review`, with `measuredSeconds: null` and native
read-aloud, language-editor and source-fidelity gates all pending. A validator pass
is not human language approval.

## Read-aloud approval pass

For each new story, read the whole Hindi telling aloud without looking at the
English sentence-by-sentence. Mark any phrase you spontaneously replace, stumble
over, or would never say to a child. Then separately check the parent note,
tradition note, close question, seed and every `ifTheyAsk`.

When the wording is settled, record the actual narration time (story blocks only),
set the native read-aloud gate with reviewer/date, then complete language-editor
and source-fidelity review. Only after all three are approved should the locale be
locked and promoted.

The URL helper already reserves the eventual reviewed edition shape as
`/s/<story>/hi/`. The preview gate also asserts that no such page is emitted yet.
